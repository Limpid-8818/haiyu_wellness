# 测试式样书与验收清单

## 1 测试层级

- 单元测试：潮汐判定、容量扣减、禁忌规则、分级审核、餐食过敏替换、指标回流。
- API 集成测试：登录与 RBAC、预约与取消、审核通过/驳回、数据持久化。
- 前端验收：客人端 10 分钟演示主线、机构端三角色跳转、移动端关键页面。
- 回归测试：需求矩阵 No.1-109 按页面/控件/验收条件逐项勾选。
