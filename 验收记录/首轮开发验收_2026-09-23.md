### 3. [P2] 环境变量示例的相对数据库路径错误

位置：[.env.example:3](/Users/wangshanchong/.codex/worktrees/64d3/haiyu_wellness/项目源码/.env.example:3)。

示例为 `DB_PATH=./server/data/community-v2.sqlite`。`npm run start`/`npm run dev` 通过 workspace 在 `项目源码/server` 工作目录启动后端，因此路径解析为 `项目源码/server/server/data/community-v2.sqlite`，偏离默认持久库。通过 `npm exec -w server -- node` 打印 cwd 和 path.resolve 已确认。组合版本后端会自动创建父目录，从而可能静默创建另一份数据库，使已有数据看似丢失。

README 中以项目源码目录的 `$PWD` 构造绝对路径的示例正确；问题限于导出 `.env.example` 中的相对值。后续应统一配置路径约定并验证从 npm workspace 启动。
