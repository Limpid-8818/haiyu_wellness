## 必须实现并验收的资源封装

本轮已在 `项目源码/scripts/resources/` 实现封装。原追加登记簿 `项目源码/output/resource-audit/registry.jsonl` 保持原样；当其剩余空间少于4 MiB时，新实例使用 `output/resource-audit/segments/<taskId>/<instanceId>/registry.jsonl`，并在 `registry-segments.jsonl` 记录路径及旧登记簿的字节数和SHA-256。每个登记簿有独立32 MiB硬上限，实例预留512 KiB清理证据空间。登记目录内的 `state/` 只放活动守护配置，清理后为空；注册表保留历史启动、失败、替换和清理事件。

`scripts/resources/audit-resource-registries.js` 以流式方式只读核对所有登记簿、分段清单、旧登记簿指纹、重复实例ID及退出证据缺口；它分别报告结构错误与历史证据不完整，不能把后者静默解释为通过。运行 `npm run resources:audit`。Unix 上 ResourceSession 默认使用 `/tmp`，避免从受管测试进程继承指向父实例内部的 `TMPDIR`，使子实例诊断目录不会随父实例清理而被提前删除。`ResourceSession` 未启动、已关闭或 guardian 身份不匹配时，`withTemporaryApi`、`withDatabaseApi`、`withMysqlDatabase` 和 `withApiAtDatabase` 必须在创建数据库、启动服务或调用业务回调前拒绝执行。

1. `resource-runtime.js` 追加登记 task ID、runner/guardian PID 与启动时间、进程 PID/启动时间/PGID/UID 稳定身份指纹、启动时可执行文件、命令、cwd、实例目录、端口、datadir、socket、日志路径和配额。身份指纹不依赖 `comm`，因此进程执行 `exec` 后仍能核对同一 PID；启动时可执行文件另行记录。启动失败、被替换和子进程均追加记录，不覆盖旧 PID；命令参数中的常见密码/令牌字段会脱敏，环境只记录变量名。
2. `resource-guardian.js` 是独立于测试回合的守护进程。默认单个日志上限 8 MiB、实例目录分配量上限 512 MiB、服务租期 15 分钟；配置只能调低。守护每 250 ms 检查租期、日志和目录用量，触限即停止服务并记录原因。
3. `resource-runner.js` 管理一个测试命令；多服务验收用同一 `ResourceSession` 启动 MySQL、API、Vite 与浏览器流程。资源全部独立启动进程组，守护跟踪子进程并为其建立 PID 身份记录。所有者正常结束、异常退出、超时、SIGINT/SIGTERM/SIGHUP 或被杀后均有对应清理路径。
4. 目录用量以文件系统 `st_blocks × 512` 计算；不可用时才使用逻辑大小按 4 KiB 向上取整。日志文件按每实例的硬字节上限截断并触发清理；终端输出只读取最多 32 KiB 尾部，守护记录最多 4 KiB 诊断尾部。
5. 清理先停浏览器/客户端和测试，再停 Vite、API、MySQL。MySQL 优先通过所属实例 socket 执行 `mysqladmin shutdown`，命令成功后还会独立等待 mysqld PID 完全退出；失败时仍只对身份核实的实例发信号，并保留诊断目录。进程组、准确 PID 和子进程均确认退出后，关闭日志句柄，限时执行 `lsof +D` 与 `lsof +L1`，两项完成且无匹配句柄才删目录。

### 运行与 Stage17 服务示例


需要让数据库、API、Vite 和浏览器共享同一生命周期时，用一个 Node 编排脚本调用 `ResourceSession`。以下展示服务规格与关闭钩子；`browserScript` 应指向仓库内会在验收结束时退出的 Playwright 脚本，端口启动前须检查空闲，不能启动脱离会话的浏览器 daemon：

```js
import path from 'node:path';
import { ResourceSession } from './scripts/resources/resource-runtime.js';

const projectRoot = process.cwd();
const browserScript = path.resolve(process.argv[2] || '');
if (!process.argv[2]) throw new Error('pass the checked-in acceptance script path as argv[2]');
const mysqlBase = '/opt/homebrew/opt/mysql@8.4';
const mysqladmin = path.join(mysqlBase, 'bin/mysqladmin');
const mysqlClient = path.join(mysqlBase, 'bin/mysql');
const mysqld = path.join(mysqlBase, 'bin/mysqld');
const apiPort = 38217;
const webPort = 5187;
const session = await ResourceSession.create({
  taskId: process.env.CODEX_TASK_ID,
  projectRoot,
  tempParent: '/tmp' // 保持 MySQL Unix socket 路径足够短
});

try {
  const datadir = await session.allocateDir('mysql-data');
  const socket = path.join(session.tempDir, 'mysql.sock');
  await session.runProcess({
    label: 'mysql-initialize', kind: 'mysql', role: 'test', command: mysqld,
    args: ['--no-defaults', `--basedir=${mysqlBase}`, `--datadir=${datadir}`,
      '--initialize-insecure', '--innodb-buffer-pool-size=48M',
      '--innodb-redo-log-capacity=48M', '--skip-log-bin', '--console'],
    cwd: projectRoot, datadir
  }, { timeoutMs: 120000 });

  await session.startProcess({
    label: 'mysql', kind: 'mysql', role: 'mysql', command: mysqld,
    args: ['--no-defaults', `--basedir=${mysqlBase}`, `--datadir=${datadir}`,
      '--bind-address=127.0.0.1', '--port=33421', '--mysqlx=0',
      `--socket=${socket}`, '--innodb-buffer-pool-size=48M',
      '--innodb-redo-log-capacity=48M', '--skip-log-bin', '--console'],
    cwd: projectRoot, datadir, socket, port: 33421,
    shutdownCommand: {
      command: mysqladmin,
      args: ['--no-defaults', '--protocol=SOCKET', `--socket=${socket}`,
        '--user=root', '--shutdown-timeout=10', 'shutdown']
    },
    shutdownTimeoutMs: 12000
  });

  await session.runProcess({
    label: 'mysql-create-isolated-acceptance-database', kind: 'mysql', role: 'test', command: mysqlClient,
    args: ['--no-defaults', '--protocol=SOCKET', `--socket=${socket}`, '--user=root',
      '--execute', 'CREATE DATABASE haiyu_acceptance CHARACTER SET utf8mb4 COLLATE utf8mb4_0900_ai_ci'],
    cwd: projectRoot, socket, datadir
  }, { timeoutMs: 15000 });

  const api = await session.startProcess({
    label: 'stage17-api', kind: 'api', role: 'api', command: process.execPath,
    args: ['src/index.js'], cwd: path.join(projectRoot, 'server'), port: apiPort,
    env: {
      PORT: String(apiPort), DB_DRIVER: 'mysql', MYSQL_HOST: '127.0.0.1', MYSQL_PORT: '33421',
      MYSQL_USER: 'root', MYSQL_PASSWORD: '', MYSQL_DATABASE: 'haiyu_acceptance', MYSQL_POOL_SIZE: '2',
      DEMO_SEED: '0',
      LLM_BASE_URL: '', LLM_API_KEY: '', LLM_MODEL: '',
      ENVIRONMENT_MODE: 'unavailable', ENVIRONMENT_LIVE: '0', QWEATHER_API_HOST: '', QWEATHER_API_KEY: '',
      QWEATHER_TIDE_STATION_ID: '', ENVIRONMENT_LOCATION_ID: '', ENVIRONMENT_LOCATION_NAME: '',
      ENVIRONMENT_LATITUDE: '', ENVIRONMENT_LONGITUDE: '', ENVIRONMENT_TIME_ZONE: '',
      OPEN_METEO_WEATHER_BASE_URL: '', OPEN_METEO_MARINE_BASE_URL: ''
    }
  });
  const vite = await session.startProcess({
    label: 'stage17-vite', kind: 'vite', role: 'vite', command: 'npm',
    args: ['run', 'dev', '--', '--host', '127.0.0.1', '--port', String(webPort), '--strictPort'],
    cwd: path.join(projectRoot, 'web'), port: webPort,
    env: { WEB_PORT: String(webPort), API_PROXY_TARGET: `http://127.0.0.1:${apiPort}` }
  });
  const browser = await session.startProcess({
    label: 'stage17-browser', kind: 'browser', role: 'browser',
    command: process.execPath, args: [browserScript, `http://127.0.0.1:${webPort}`],
    cwd: projectRoot
  });
  const result = await session.waitProcess(browser.id, 12 * 60 * 1000);
  if (result.status !== 'exited' || result.exitCode !== 0) throw new Error('browser acceptance failed');
  void api;
  void vite;
} finally {
  await session.close('stage17-acceptance-complete');
}
```

## 正确退出和删除顺序

1. 停止本实例的测试请求、API、Vite和浏览器客户端。
2. 对临时MySQL用该实例的socket请求关闭，例如：\
