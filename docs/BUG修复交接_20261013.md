## 拉取与配置

新同学可执行：

```bash
git clone https://github.com/Peppa12138/haiyu_wellness.git
cd haiyu_wellness/项目源码
npm ci --ignore-scripts
cp .env.example .env
```

随后按启动手册生成自己的AUTH_SECRET，使用自己获授权的模型Key。已有本地.env时逐项合并配置，不覆盖自己的Key或数据库路径。仅有代码而没有Key时，助手进入引导模式，不能据此验证真实模型。

当前示例公开配置与原开发机一致：DeepSeek兼容接口、deepseek-flash、共享50次模型/8192总Token/12工具/90秒预算，以及大连开发区地区代表点Open-Meteo真实天气和模式海面高度。实际私密.env没有提交；预算风险R01仍待复测，机构地点/批准阈值及台站潮位仍不能由示例配置冒充。

开发者应使用自己的新SQLite库。需要演示账号时，仅对空库执行 `DEMO_SEED=1 npm run dev`，会创建guest_demo、staff_demo、dean_demo；staff_demo只有医护岗位，其他岗位需按BUG-F05和V02安排专门的合成账号/分工。原开发机的Yifu Guo、订单和档案不随Git传输；复现该客人的问题请按BUG条目在合成账号上建立对应前置，不假装新库已有该数据。
