- 复核尾部用例的疗程草案前置使用与 `scripts/demo-mock-data.mjs` 相同的隔离 SQL 夹具（仅目录级前置，不伪造审批事件）；`source_run_id` 保持 NULL 以满足 `agent_runs` 外键。
- 改期用例使用 `scripts/bugfix-stage5/fixtures.js` 的离线环境快照夹具（`ENVIRONMENT_OFFLINE_FIXTURE=1`，不发起外部 HTTP）；演示环境下户外时段方可评估，live 快照因机构阈值未确认而拦截（产品诚实设计，测试同时断言了该拦截）。
