2026-10-13已在当前本地开发环境完成配置并实际查看网页。地点使用项目已有的大连经济技术开发区公开地区代表点，精度按用户选定的默认方案；不把该点当机构精确地址。

## 配置

在`项目源码/.env`中追加或修改以下条目，保留已有模型Key、数据库等其他配置：

```dotenv
ENVIRONMENT_MODE=live
ENVIRONMENT_LIVE=1
ENVIRONMENT_TIDE_PROVIDER=open-meteo
ENVIRONMENT_LOCATION_ID=dalian-etdz-region-representative
ENVIRONMENT_LOCATION_NAME=大连经济技术开发区地区代表点（非机构精确地址）
ENVIRONMENT_LATITUDE=39.052585
ENVIRONMENT_LONGITUDE=121.787513
ENVIRONMENT_TIME_ZONE=Asia/Shanghai
ENVIRONMENT_COORDINATES_STATUS=region-representative
ENVIRONMENT_INSTITUTION_LOCATION_CONFIGURED=0
ENVIRONMENT_LOCATION_SOURCE="https://www.wikidata.org/wiki/Q1000487#P625"
OPEN_METEO_WEATHER_BASE_URL=https://api.open-meteo.com/v1/forecast
OPEN_METEO_MARINE_BASE_URL=https://marine-api.open-meteo.com/v1/marine
```

此模式不需要QWeather Key、账号Host或台站ID。天气由Weather Forecast API获取；波高与含潮汐的模式海面高度由同一次Marine响应提供，避免重复潮汐请求。模式海面高度的基准和定义见[Open-Meteo Marine文档](https://open-meteo.com/en/docs/marine-weather-api)。

`.env`保持Git忽略，不写入仓库。普通`npm start`需要重新启动API才读到新配置；`npm run dev`的Node文件监听会在入口重载后读到配置。本次已让现有开发后端重载，入口JS内容未改，前端进程保留。

## 网页检查

1. 打开现有网页`http://127.0.0.1:5180/`，进入“管家”。
2. 查看“今日天气与潮汐”：应显示大连开发区地区代表点、坐标、Asia/Shanghai，以及“来源数据可用”。
3. 查看天气、波高和“含潮汐的模式海面高度（预测）”，并展开其预测曲线；确认供应商网格坐标、获取时间和有效期有值。
4. “站点潮位：当前模式不提供”和“当前模式不提供站点精确潮汐时刻”是本方案的明确边界，不需要填写假的台站ID。

本次实际样本：气温15.5°C、风速18.1km/h、波高0.4m、模式海面高度1.19m；曲线展开后范围为-1.21至1.57m。这些仅为本次获取结果，后续数据会更新，不能硬编码。

天气供应商网格中心为39.0510/121.7284；Marine网格中心为38.9583/121.7917。地区查询坐标与供应商网格中心分开显示，不伪称同一精确站点。
